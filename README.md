# Hari Reddy — Cinematic Portfolio

A responsive, static HTML/CSS/JS portfolio starter for a filmmaker, cinematographer and video editor.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Personalize before publishing
Search `index.html` for these placeholders:
- `hello@yourdomain.com` — replace with your professional email.
- Social links marked `href="#"` — replace with your real Instagram, YouTube and LinkedIn URLs.
- Project cards — replace sample images with your own posters/stills and update descriptions, credits, years and project links.
- Replace the theatre/landscape images with your own work when ready. Current photos are remote Unsplash images and require internet access.

To use your own images, create an `images` folder and replace e.g.
`https://images.unsplash.com/...` with `images/room-307-poster.jpg`.

## Publish to your existing domain
You need access to your domain's DNS and a hosting service. A simple static host such as Netlify, Vercel, or GitHub Pages can host these files.
1. Upload/deploy the contents of this folder (the `index.html`, `style.css`, and `script.js` files must be at the published root).
2. In the hosting dashboard, add your existing domain.
3. Follow the host's exact DNS instructions at your domain registrar.
4. Wait for DNS/SSL provisioning, then test the site on phone and desktop.

Do not change nameservers or delete existing DNS records unless your hosting provider's instructions specifically require it. If the domain already hosts email or another site, preserve its MX and other required records.

## Notes
- This is a front-end starter; it does not include a CMS, analytics, or a contact form backend.
- The email CTA opens the visitor's email app using `mailto:`.
- Update the page title and meta description in `index.html` if you change your branding.
